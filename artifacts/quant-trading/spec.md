# 퀀트 포트폴리오 최적화 대시보드 — Spec

## 개요

퀀트 지식이 없는 초보 투자자가 큐레이션된 미국 주식 번들을 골라 포트폴리오 최적화를 실행하고, 결과를 저장·비교할 수 있는 개인 전용 대시보드. 모든 용어와 지표에 툴팁 설명이 붙어 있어 코드나 금융 지식 없이도 사용할 수 있다.

## 범위

### 포함
- 큐레이션 번들 갤러리 탐색
- 번들 내 종목 추가/제거 (세션 중 수정)
- 최적화 방법 선택 및 실행 (Max Sharpe / Min Variance / Risk Parity)
- 효율적 프론티어 시각화
- 최적 가중치 파이차트
- 핵심 지표 (연환산 수익률, 변동성, 샤프비율, MDD)
- 백테스팅 — 프리셋 기간 (1년/3년/5년/10년) vs Buy & Hold 비교
- 용어·지표 "?" 아이콘 툴팁
- 결과 로컬 저장 및 기록 페이지에서 불러오기
- 두 결과 나란히 비교

### 제외
- 실거래 / 페이퍼 트레이딩 — MVP 범위 밖
- 국내 주식 — US 시장으로 핵심 가정 먼저 검증
- 실시간 시세 — 히스토리컬 데이터만 사용
- 사용자 정의 번들 생성 — 기존 번들 수정만 허용
- 3개 이상 동시 비교 — 2개로 제한
- Fama-French 팩터 모델 — MVP 이후

## 시나리오

### 1. 번들 갤러리 탐색

- **Given** — 앱 첫 화면
- **When** — 사용자가 앱에 접속
- **Then** — 번들 카드 목록이 표시되며 카테고리(테마형/팩터형/전통 배분) 구분과 함께 각 카드에 번들 이름, 포함 종목 수, 한 줄 설명이 보인다

성공 기준:
- [ ] 번들 카드가 1개 이상 표시된다
- [ ] 각 카드에 번들 이름, 카테고리, 포함 종목 수, 한 줄 설명이 보인다

---

### 2. 번들 선택 및 종목 확인

- **Given** — 번들 갤러리 화면
- **When** — 사용자가 특정 번들 카드를 클릭
- **Then** — 해당 번들의 상세 화면으로 이동하며, 포함된 종목 카드 목록(티커·회사명·한 줄 설명)과 최적화 방법 선택 UI가 함께 표시된다

성공 기준:
- [ ] 번들 클릭 시 해당 번들의 종목 목록이 표시된다
- [ ] 각 종목 카드에 티커, 회사명, 한 줄 설명이 보인다
- [ ] Max Sharpe / Min Variance / Risk Parity 선택 UI가 표시된다

---

### 3. 용어 툴팁 확인

- **Given** — 번들 상세 화면 또는 결과 화면에서 "?" 아이콘이 있는 용어·지표가 보임
- **When** — 사용자가 "?" 아이콘에 마우스를 올림
- **Then** — 해당 용어의 초보자용 설명 팝오버가 열린다. 마우스를 벗어나면 팝오버가 닫힌다.

성공 기준:
- [ ] "?" 아이콘 hover 시 팝오버가 표시된다
- [ ] 팝오버에 해당 용어의 초보자용 설명 텍스트가 들어 있다
- [ ] 마우스를 벗어나면 팝오버가 닫힌다

---

### 4. 번들 내 종목 수정

- **Given** — 번들 상세 화면, 종목이 3개 이상 있음
- **When** — 사용자가 종목 카드의 제거 버튼을 클릭
- **Then** — 해당 종목 카드가 목록에서 즉시 사라진다. 종목이 정확히 2개가 되면 모든 제거 버튼이 비활성화된다.

성공 기준:
- [ ] 제거 버튼 클릭 시 해당 종목이 목록에서 사라진다
- [ ] 종목이 2개일 때 제거 버튼이 비활성화된다
- [ ] 수정된 종목 목록은 이후 최적화 실행에 반영된다

---

### 5. 최적화 실행 및 로딩

- **Given** — 번들 상세 화면, 최적화 방법 선택됨
- **When** — 사용자가 "최적화 실행" 버튼을 클릭
- **Then** — 로딩 스피너와 함께 "데이터 가져오는 중...", "계산 중..." 메시지가 순차적으로 표시되다가, 완료 후 결과 화면으로 전환된다

성공 기준:
- [ ] 버튼 클릭 즉시 로딩 스피너가 표시된다
- [ ] "데이터 가져오는 중..." 메시지가 표시된다
- [ ] "계산 중..." 메시지가 표시된다
- [ ] 완료 후 효율적 프론티어 차트, 가중치 파이차트, 핵심 지표 카드가 표시된다

---

### 6. 결과 확인 — 효율적 프론티어

- **Given** — 최적화 완료된 결과 화면
- **When** — 사용자가 화면을 확인
- **Then** — X축(변동성) · Y축(기대수익률) 산점도에 다수의 포트폴리오 점과 최적 포트폴리오 점이 다른 색·크기로 강조 표시된다

성공 기준:
- [ ] 효율적 프론티어 산점도가 표시된다
- [ ] 최적 포트폴리오 점이 다른 색·크기로 강조 표시된다
- [ ] X축 "변동성", Y축 "기대수익률" 레이블이 표시된다

---

### 7. 결과 확인 — 핵심 지표

- **Given** — 최적화 완료된 결과 화면
- **When** — 사용자가 화면을 확인
- **Then** — 연환산 수익률, 변동성, 샤프비율, MDD가 각각 카드로 표시되고, 각 카드 옆에 "?" 아이콘이 보인다

성공 기준:
- [ ] 연환산 수익률, 변동성, 샤프비율, MDD 4개 지표 카드가 모두 표시된다
- [ ] 각 카드 옆에 "?" 아이콘이 표시된다

---

### 8. 백테스팅 실행

- **Given** — 결과 화면
- **When** — 사용자가 백테스팅 기간 프리셋(1년/3년/5년/10년) 중 하나를 선택
- **Then** — 최적 가중치 포트폴리오와 Buy & Hold의 수익률 곡선이 같은 차트 안에 함께 표시된다

성공 기준:
- [ ] 1년/3년/5년/10년 프리셋 버튼이 표시된다
- [ ] 프리셋 선택 시 두 수익률 곡선이 하나의 차트에 표시된다
- [ ] 범례에 "최적 포트폴리오"와 "Buy & Hold"가 구분 표시된다

---

### 9. 결과 저장

- **Given** — 결과 화면
- **When** — 사용자가 "결과 저장" 버튼을 클릭
- **Then** — "저장됨" 확인 메시지가 표시되고, 기록 페이지에서 해당 결과를 불러올 수 있게 된다

성공 기준:
- [ ] "결과 저장" 버튼이 결과 화면에 표시된다
- [ ] 버튼 클릭 시 "저장됨" 메시지가 표시된다
- [ ] 저장 후 기록 페이지 목록에 해당 결과가 나타난다

---

### 10. 기록 페이지에서 이전 결과 불러오기

- **Given** — 기록 페이지, 저장된 결과가 1개 이상 있음
- **When** — 사용자가 기록 페이지에 접속
- **Then** — 저장된 결과 목록이 최신순으로 표시되며, 각 항목에 번들명·최적화 방법·저장 일시가 보인다. 항목 클릭 시 해당 결과 화면으로 이동한다.

성공 기준:
- [ ] 저장된 결과가 최신순으로 표시된다
- [ ] 각 항목에 번들명, 최적화 방법, 저장 일시가 표시된다
- [ ] 항목 클릭 시 해당 결과 화면이 표시된다

---

### 11. 두 결과 비교

- **Given** — 기록 페이지, 저장된 결과가 2개 이상 있음
- **When** — 사용자가 체크박스로 결과 2개를 선택하고 "비교" 버튼을 클릭
- **Then** — 두 결과의 핵심 지표(연환산 수익률, 변동성, 샤프비율, MDD)와 가중치 파이차트가 나란히 표시된다

성공 기준:
- [ ] 기록 페이지에서 결과를 2개까지 체크박스로 선택할 수 있다
- [ ] 2개 선택 시 "비교" 버튼이 활성화된다
- [ ] 비교 화면에 두 결과의 핵심 지표가 나란히 표시된다
- [ ] 비교 화면에 두 결과의 가중치 파이차트가 나란히 표시된다

---

### 12. 데이터 로드 실패

- **Given** — 최적화 실행 중
- **When** — 외부 데이터 수집에 실패
- **Then** — "데이터를 가져오지 못했습니다. 잠시 후 다시 시도해주세요." 메시지와 재시도 버튼이 표시된다

성공 기준:
- [ ] 에러 메시지가 표시된다
- [ ] 재시도 버튼이 표시된다
- [ ] 재시도 버튼 클릭 시 최적화를 다시 실행한다

---

## 불변 규칙

**성능**
- 로컬 캐시가 있는 경우 최적화 결과까지 5초 이내에 표시된다
- 첫 데이터 수집(캐시 없음) 완료까지 10초 이내다

## 의존성

- yfinance를 통한 미국 주식 히스토리컬 일봉 데이터 수집 가능

## 미결정 항목

- 리스크 성향 설문 → 맞춤 번들 추천 기능 MVP 포함 여부
- 번들 정의 방식: 하드코딩 JSON vs 로컬 DB 테이블 관리
- 효율적 프론티어 계산: 몬테카를로 샘플링 vs 해석적 풀이
- 로컬 캐시 만료 정책 (일봉 데이터 갱신 주기)

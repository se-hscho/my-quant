# 포트폴리오 관리 에이전트

## Problem Statement

HMW — 개인 투자자가 기관·외국인의 자금 흐름을 **그대로 따라갈 수는 없지만**,
그들의 **방향과 제약**을 이해해 개인만의 유연성으로 맞춤 추종·선점하고,
**뉴스·공시·정책·증권사 애널리스트 리포트·이벤트**를 놓치지 않도록 매일 배분·시점·근거를 제시받을 수 있을까?

## 근본 아이디어 (Foundational Thesis)

> **개인은 대규모 자산을 운용하는 기관·외국인을 1:1로 따라갈 수 없다.**
> 다만 그들이 갖는 **제약**과 개인이 갖는 **유연성**을 이해하면,
> 같은 방향을 **다른 속도·규모·기간**으로 실행해 오히려 유리해질 수 있다.

### 기관·외국인 vs 개인

| | 기관·외국인 | 개인 (우리가 쓸 이점) |
|---|---|---|
| **규모** | 매매가 시장에 영향, 체결·청산에 수주~수개월 | 소액 즉시 체결, 한 종목 비중 자유 |
| **규칙** | mandate·지수추종·내부 리스크 한도 | 현금·섹터·지역 제약 없음 |
| **정보 공개** | 13F·펀드 공시 **지연** (미국 45일 등) | 지연 구간에도 **방향은 읽고 선행·후행 선택** |
| **압력** | 분기 성과·환매·보고 의무 | 기간 조절 — 단기 회피·장기 보유 자유 |
| **의무** | 벤치마크 대비 최소 추적 | 벤치 불필요, 현금 100%도 가능 |

에이전트의 Follow/선점은 **"기관이 가려는 방향"을 읽되, 개인 실행 가능한 형태로 번역**하는 것이다.

### 스마트 머니 신호 (방향 읽기)

| 신호 | 용도 |
|---|---|
| **외국인·기관 순매수** (한국 KRX 등) | 섹터·종목 수급 방향 |
| **섹터·지역 ETF 자금 흐름** | 글로벌 rotation |
| **공시·13F·펀드 보유 변화** | 분기·지연 반영, "아직 구축 중" vs "이미 완료" |
| **정책·금리·규제** | 채권·금·주식 배분 shift |
| **뉴스·이벤트** | 단기 변동성·시나리오 전환 트리거 |
| **증권사 애널 리포트** | 종목·섹터·시장 전망, 목표가·투자의견 | 보유·유입 섹터 제안·시나리오 보강 |

### 뉴스·공시·정책·애널리스트·이벤트 레이어 (필수)

순수 가격 momentum만으로 제안하지 않는다. **맥락**을 붙인다.

| 유형 | 예시 | 제안에 반영 |
|---|---|---|
| **정책** | FOMC, 한국 금통위, BOJ, 관세·보조금 | 금리·환율·섹터 배분 shift |
| **공시** | 실적, M&A, 유상증자, 지분 변동 (DART·EDGAR) | **보유 종목** 시나리오·시점 변경 |
| **뉴스** | 지정학, 산업 규제, 빅테크 실적 | 섹터 흐름 해석·Follow↔선점 전환 |
| **증권사 애널 리포트** | 한국·미국·일본 리서치 (종목/섹터/시장) | 투자의견·목표가·핵심 논거 → 제안·상세 근거 |
| **캘린더 이벤트** | CPI, 고용, 실적 시즌, 옵션 만기 | 사전·당일·사후 **방향 제안 + 근거** |

#### 증권사 애널리스트 리포트 참조

**보유 종목·유입 섹터·시장 전망**에 대해 당일·최근 리포트를 수집·요약해 맥락 브리핑·상세 근거에 인용한다.

| 지역 | 참조 대상 (예) | MVP 수집 방식 |
|---|---|---|
| **한국** | 미래에셋, 삼성, 한투, NH, 키움, KB 등 | 네이버·FnGuide 공개 리서치 요약, 제목·투자의견·목표가 |
| **미국** | Goldman, MS, JPM 등 sell-side | 공개 헤드라인·요약 API / LLM 검색 grounding |
| **일본** | 닛케이·현지 증권 리서치 | 공개 요약·영문 번역 요약 |

**브리핑에 넣는 형식**

```
📊 애널리스트 참고 (보유: 삼성전자)
  • 미래에셋 (7/1): Buy, 목표가 95,000 — HBM 수요 상향
  • 한국투자 (6/28): Hold — 단기 밸류에이션 부담
  → 종합: 섹터 유입 Follow와 부합, 선점 안은 목표가 대비 여유 시
  [상세] 리포트 요약·반대 의견·우리 제안과의 정합성
```

**원칙**
- **출처 명시** — 증권사명·날짜·투자의견 (가능 시 목표가)
- **다수 의견** — 같은 종목/섹터 2건 이상 있으면 요약·상반 의견 병기
- **우리 제안과 연결** — "애널 Buy 다수 + 외국인 순매수 → Follow SOXX 확대 근거"
- **저작권** — 전문 전재 대신 **요약·인용**; 원문 링크(공개 URL 있을 때)
- **상세 페이지** — 초보자용: "애널리스트 리포트란?", 투자의견·목표가 의미 설명

**현실적 범위**
- 대부분 증권사 리포트는 **유료·로그인** → MVP는 **공개 요약·헤드라인·메타데이터** 우선
- Phase 2: FnGuide/WISEreport 등 **유료 API** 또는 사용자 증권사 리서치 연동
- 리포트 없는 종목은 수급·가격·뉴스만으로 근거 구성 (공백 명시)

**주요 이벤트 처리 원칙**

1. **놓치지 않음** — 이벤트 전·당일·후 브리핑·알림 (이메일/Slack)
2. **방향 명시** — "무엇을 늘리고/줄이고/현금 유지" (시나리오 안 갱신)
3. **근거 필수** — 수치(수급·가격) + 뉴스/공시/정책/**애널 리포트** 인용 요약
4. **개인 관점 번역** — "기관은 청산 불가하지만 개인은 현금 20%로 단기 대응 가능" 등

이벤트 브리핑 예:

```
📅 FOMC 금리 동결 + 비둘기적 서명
  기관 관점: 듀레이션 확대 이미 진행 중, 대형주 유입 지속
  개인 이점: 즉시 채권 ETF(AGG) +2%p, 현금에서 전환 가능
  제안 변경: 안1 Follow → 채권 비중 상향
  보유 영향: AGG 10%→14%, SOXX 유지
  근거: [연준 성명] + [채권 ETF 1d/7d] + [NH투자증권 채권 전망 6/30 요약]
```

## Recommended Direction

**스마트 머니 방향 추종(개인 맞춤) + 맥락 기반 배분 코치 + 일일·이벤트 브리핑 에이전트.**

목표 비중을 미리 정해 두지 않는다.
**기관·외국인·시장의 자금 방향**과 **뉴스·공시·정책·증권사 애널 리포트**를 함께 보고
개인 제약·이점에 맞게 **Follow / 선점 / 최소변경** 시나리오를 제안한다.

**자산군 요약만이 아니다** — 사용자가 보유한 **개별 ETF·종목·섹터 ETF** 단위까지
내려가서 비중·수익률·제안을 산출한다.

### 분석·제안 계층 (4단)

| 계층 | 예시 | 역할 |
|---|---|---|
| **L0 통화·현금** | KRW / USD / JPY 현금 | 환전·결제 재원, 환율 노출 |
| **L1 자산군** | 주식 / 채권 / 금 / 현금 | 전체 그림·리스크 요약 |
| **L2 지역** | 한국 / 미국 / 일본 | 지역 rotation |
| **L3 섹터** | 반도체, 헬스케어, 에너지, 금융… | 섹터 ETF·지수 기반 자금 흐름 |
| **L4 보유 종목** | SOXX, 069500.KS, 005930.KS… | **내가 실제 가진 티커** 비중·제안 |

- 보유가 **섹터 ETF**(SOXX, XLK, 091160.KS 등)면 L3·L4가 일치하거나 L4가 주 제안 단위
- 보유가 **개별 종목**(삼성전자, NVDA)이면 섹터 매핑 후 L3 흐름과 L4 종목 제안을 연결
- 시장 레이더는 **전 섹터** proxy ETF로 자금 흐름을 본다 — 내가 반도체만 갖고 있어도 헬스케어·에너지 등 **다른 섹터 유입/유출**이 보임
- L4는 내 보유 종목 + **미보유 섹터에 대한 신규 ETF·종목 추천** (유입 섹터 → 대표 티커 제안)
- 제안은 **비중 숫자만**이 아니라 **조정 방법**(어디서 줄이고 어디에 넣을지)과 **시나리오별 전·후 비교**로 제시

제안 비중표는 **요약( L1~L3 ) + 보유 종목별( L4 ) + 신규 추천 종목 + 시나리오 비교**를 제공한다.

### 크로스 섹터 자금 흐름 & 신규 추천

내 보유 섹터와 무관하게 **전체 섹터 히트맵**을 매일 표시한다.

```
섹터 자금 흐름 (7일 상대강도 예)
  반도체  ████████░░  +8%   ← 내 보유
  에너지  ██████████  +12%  ← 미보유, 유입 1위
  헬스케어 ████░░░░░░  -3%  ← 내 보유 XLV
  금융    ██████░░░░  +5%   ← 미보유
```

- **미보유 + 유입 상위 섹터** → 해당 섹터 **대표 ETF·종목 추천** (예: 에너지 유입 → XLE, 261220.KS)
- **보유 + 유출 섹터** → 축소·대체 섹터 제안
- 추천 티커는 lookup 테이블의 섹터별 proxy + LLM narrative (면책: "검토용 제안")

### 시나리오 안 (전·후 비교)

매일 **여러 안**을 만들어 **현재(Before) vs 변경 후(After)** 를 나란히 비교한다.

| 안 | 설명 |
|---|---|
| **안 0 — 현재 유지** | baseline, 조정 없음 |
| **안 1 — Follow** | 추세 추종 배분 |
| **안 2 — 선점** | 선행 배분 |
| **안 3 — 최소 변경** (선택) | 핵심 1~2종목만 조정, 거래 비용·세금 고려 |

**각 안마다 동일 지표로 비교:**

| 항목 | Before (현재) | After (해당 안) | Δ |
|---|---|---|---|
| 포트 예상 수익률 (추세 기반)* | 4.2% | 6.1% | +1.9%p |
| **환율 영향 (KRW 기준)*** | — | USD/KRW -1.2% 반영 | — |
| 예상 변동성* | 12% | 14% | +2%p |
| 지역·섹터·종목 비중 | … | … | diff 표 |
| **통화별 현금** | KRW 30% / USD 15% | KRW 22% / USD 20% | 환전 포함 |
| 조정 방법 | — | 환전·매수·매도·현금 | — |
| **환전 시점** | — | 7일 내 KRW→USD $○○ | 근거 |
| 근거 | — | 섹터 흐름·추세·선점 신호 | — |
| 리밸런싱 시점 | — | 실행 창·트리거 | — |

\* **추세 기반 예상 수익률**: 최근 7d/1mo/분기 momentum·섹터 상대강도로 가중 평균한 **전향 참고치** (보장 수익 아님). spec에서 계산 규칙 고정.

**비중 조정 방법 (Adjustment Playbook)** — 각 안에 구체적 액션:

```
안 1 Follow — 조정 예시 (환전 포함)
  ⓪ 환전      KRW 2,000만 → USD $14,000  (7일 내, 달러 약세 구간 Follow)
  ① SOXX      3% → 6%   (+3%p)  USD 현금에서 매수
  ② XLE (신규) 0% → 4%   (+4%p)  USD 현금에서 매수
  ③ XLV       15% → 12%  (-3%p)  USD 종목 매도
  ④ KRW 현금  30% → 22%  (-8%p)  환전 재원
  ⑤ USD 현금  15% → 20%  (+5%p)  환전 유입 후 투자
  → 통화별 현금 합계·총자산 100% 유지
```

- 미국·일본 매수 제안 시 **해당 통화 현금 부족** → 환전 단계를 playbook **맨 앞**에 삽입
- 환전만 하고 매수는 보류하는 **안**도 가능 (환율 선점)

### 핵심 루프

```
수동 보유 등록
    → 스마트 머니·섹터·지역 자금 흐름 (기관/외국인 수급 + ETF proxy)
    → 뉴스·공시·정책·**애널 리포트**·이벤트 캘린더 수집·요약
    → 기관 제약 vs 개인 이점 번역 (속도·규모·기간)
    → 미보유 유입 섹터 ETF·종목 추천
    → 안 0~N 시나리오 (Before/After, playbook, **환전 시점**, 추세 기반 예상 수익률)
    → 이벤트 시: 방향 변경 + 근거 + 알림 (놓침 방지)
    → 매일 아침 + 이벤트 트리거 이메일·Slack + /agent
```

### 제안 철학 (목표 비중 ❌ → 시장 추세 ✅)

| 기존(버림) | 새 방향 |
|---|---|
| 사용자가 60/40 목표 설정 | 스마트 머니 **방향** + 맥락으로 제안 |
| 가격 momentum만 | **뉴스·공시·정책·이벤트** 결합 |
| 기관과 동일 속도 추종 | 기관 **제약 고려** + 개인 **기간·규모 조절** |
| "목표에 맞게 리밸런싱" | 이벤트 시 **방향 전환 + 근거**로 놓침 방지 |

제안 유형 예:
- **크로스 섹터** — "보유는 반도체 뿐이나 에너지 7일 +12% 유입 → **미보유** XLE·261220.KS 편입 검토"
- **Fast Follow (L4)** — "SOXX 3% → 9%, 재원: 현금 6%p"
- **선점 (L4)** — "헬스케어 약세 전환 초기, XLV 15% → 8% 선행 축소 → 재원 에너지 신규"
- **시나리오 비교** — "안0 유지 4.2% vs 안1 Follow 6.1% vs 안2 선점 7.0% (추세 기반 1mo 전향)"
- **방향 변경** — "어제 에너지 Follow → 오늘은 금리 이벤트로 안3 최소변경 권고"

| 환율 | USD/KRW, JPY/KRW, USD/JPY | Yahoo FX, 1d/7d/1mo 추세 |

### 환율·통화 레이어 (필수)

미국·일본 투자 시 **원화 현금과 달러(·엔) 현금이 분리**되어 있으므로,
종목 비중 제안과 **환전을 한 세트**로 다룬다.

**보유 현금 구조**

```
현금 (통화별 분리 입력)
  ├─ KRW  ₩50,000,000
  ├─ USD  $12,000
  └─ JPY  ¥500,000  (일본 투자 시)
```

**에이전트가 추가로 제시**

| 항목 | 설명 |
|---|---|
| **통화별 현금 비중** | 총자산 대비 KRW/USD/JPY 현금 % |
| **환전 필요량** | 미국 매수 안 실행 시 "KRW → USD ○○" |
| **환전 시점** | 즉시 / N일 내 / 이벤트 후 / 보류 + **트리거** |
| **환율 근거** | USD/KRW 추세, 금리차, FOMC·금통위, 외국인 수급 |
| **Follow vs 선점** | Follow: 추세 환전 / 선점: 달러 약세·강세 전환 전 환전 |
| **환율 리스크** | 미국 주식 수익률에 FX 합산·분리 표시 (KRW 기준) |

**환전 시점 예시**

```
💱 환전 제안 (안 1 Follow)
  행동: KRW 2,000만 → USD 약 $14,000
  시점: 7일 내 (FOMC 전 선환전)
  근거: USD/KRW 7일 -0.8% (달러 약세), 미국 ETF 매수 예정(SOXX+XLE)
  선점 안: FOMC 후 환율 재평가 — 비둘기면 추가 환전, 매파면 일부 보류
```

- 한국 종목 매수 → **KRW 현금**에서만
- 미국 종목·ETF → **USD 현금** 우선, 부족 시 **환전 후** 매수
- 일본 → **JPY** 동일 패턴
- 환전만 먼저·매수는 나중 — **환율 선점** 시나리오로 별도 안 가능

### 보유 데이터

**MVP: 수동 입력만.** (CSV·증권사 연동은 Phase 2)

- **티커·수량·통화** (개별 주식·섹터 ETF·채권·금 ETF 모두 동일 입력)
- 종목 유형: 주식 / ETF / 채권ETF / 금ETF / 현금 (ETF는 섹터·지역 자동·반자동 분류)
- **현금 잔액 — 통화별 분리** (KRW / USD / JPY 각각)
- 종목은 **결제 통화** 명시 (미국 티커 = USD, 한국 = KRW 등)
- 갱신은 사용자가 직접 (매수/매도 후)

섹터·지역 메타데이터: 티커 lookup 테이블 + 없으면 사용자가 섹터 태그 지정 (예: SOXX → 반도체)

### 알림

- **매일 아침 정해진 시각** (기본 KST 07:00, 사용자 설정 가능)
- **이메일** + **Slack** 동시 지원 (각각 opt-in)
- 내용: 브리핑 요약 + /agent 상세 링크
- 스케줄: 서버 cron (Vercel Cron / 외부 scheduler)

### LLM — Cursor vs Gemini?

| | Cursor | Gemini (Google AI) |
|---|---|---|
| **정체** | 코딩용 IDE·에이전트 런타임 | 클라우드 LLM API |
| **포트폴리오 앱 연동** | ❌ 일반 앱이 Cursor에 붙어서 알림 받는 구조 아님 | ✅ API 키로 서버에서 호출 |
| **역할** | 이 프로젝트를 **개발할 때** 쓰는 도구 | 배포된 앱의 **브리핑·대화 엔진** 후보 |

**정리**
- **Cursor 연동** = 포트폴리오 에이전트가 Cursor IDE 안에서 돌아가거나 Cursor로 알림이 오는 것 → **불가/비권장**. Cursor는 개발 환경이지 운영 채널이 아니다.
- **Gemini 연동** = `GOOGLE_GENERATIVE_AI_API_KEY`로 서버에서 브리핑 생성·채팅 → **MVP LLM 1순위 추천** (비용·한국어·구조화 출력 양호)
- 대안: **Claude API**, **OpenAI API** — 동일 패턴으로 교체 가능. plan 단계에서 추상화.

알림 채널은 **이메일(Resend 등) + Slack Incoming Webhook**이 맞고, Cursor와는 무관하다.

### 에이전트가 매일 전달할 내용

1. **내 포트 스냅샷** — 비중·수익률 + **통화별 현금 (KRW/USD/JPY)**
2. **환율 브리핑** — USD/KRW·JPY/KRW 추세, 환전 시점 요약
3. **스마트 머니·전 섹터 흐름** — 기관/외국인 수급 + 섹터 ETF 상대강도
4. **맥락 브리핑** — 뉴스·공시·정책·**증권사 애널 요약**(보유·유입 섹터)
5. **이벤트 알림** — 당일·다가올 이벤트 → **배분 방향 변경 제안 + 근거** (놓침 방지)
6. **기관 vs 개인 렌즈** — "기관은 X 제약 → 개인은 Y로 대응 가능"
7. **신규 추천** — 미보유 유입 섹터 ETF·종목
8. **시나리오 안 (Before/After)** — playbook에 **환전 단계** 포함, FX 반영 수익률
9. **리밸런싱·환전 시점** — 안별·종목별·**환전** 실행 창·트리거
10. **방향 변경** — 전일·이벤트 전 대비 diff
11. **대화** — /agent 심화 Q&A

> 예상 수익률·이벤트 영향은 **참고용**이며 투자 보장 아님 — 면책 고정.

### 레포트·브리핑 UX (시각화 + 설명)

**원칙: 한눈에 보이게(표·차트·도식) + 이해할 수 있게(설명·근거) — 둘 다 필수.**

차트만 던지지 않는다. 모든 시각 요소는 **해석 문단**과 **행동 제안**을 동반한다.

#### 정보 구조: 1페이지 요약 → 상세 (초보자용)

```
┌─────────────────────────────────────┐
│  PAGE 1 — 요약 (Summary)            │
│  • 오늘 결론 3~5줄                   │
│  • 핵심 차트·표만 (스캔 30초)         │
│  • 추천 안 1줄 + 환전·시점 한 줄      │
│  • [상세 보기] / 스크롤 ↓             │
└─────────────────────────────────────┘
          ↓
┌─────────────────────────────────────┐
│  PAGE 2+ — 상세 (Detail)            │
│  • 섹션별: 시각 → 해석 → 근거 → 행동  │
│  • 투자 초보자도 이해 가능한 문장     │
│  • 용어 첫 등장 시 짧은 정의(툴팁)    │
│  • 왜 이 제안인지, 무엇을 놓치면 안 되는지 │
└─────────────────────────────────────┘
```

**1페이지(요약)에만 넣을 것**
- 오늘의 한 줄 결론
- 포트 총자산·전일 대비·통화별 현금 스냅샷
- 섹터 흐름 top3·이벤트 알림 유무
- 시나리오 안 **한 줄 비교** (안0/1/2 수익·변동성 막대 1개)
- 환전·리밸런싱 **시점 한 줄**
- CTA: 이메일/Slack은 "상세 보기" 링크 → `/agent` 상세

**상세 페이지에 넣을 것** (근거·초보자 설명)
- 각 차트 아래 **"이게 무슨 뜻인가"** 2~4문장
- **기관 vs 개인** — 왜 기관과 다르게 행동할 수 있는지
- **Follow / 선점** — 각 안 playbook 단계별 설명
- **환전** — 환율·금리·이벤트가 왜 시점에 영향을 주는지
- **이벤트** — 뉴스·공시·정책·**애널 리포트** 인용 + 배분에 미치는 이유
- **용어 사전 톤** — 샤프비율·%p·순매수·rotation 등 첫 등장 시 설명
- **면책** — 예상 수익률·참고용 고지

**초보자 가독성 규칙**
- 문장: 짧게, **한 문단 = 한 메시지**
- 숫자 뒤에 **맥락** (예: "3%p 증가 = 총자산 1억 기준 약 300만원 규모")
- 비교는 **Before/After 표**로, 추상적 표현 최소화
- "검토하세요" / "고려해보세요" 톤 — 확정 매매 지시 금지

```
[시각] 차트·표·도식  →  [해석] 2~4문장 "무슨 뜻인가"  →  [행동] 무엇을 검토할지
```

#### 채널별 형태

| 채널 | 시각화 | 설명 |
|---|---|---|
| **`/agent` 웹** | **1페이지 요약** + 스크롤/탭 **상세** | 인터랙티브 차트, 용어 툴팁, 섹션별 근거 |
| **이메일** | **본문 = 요약** (차트 이미지 1~2개) | "상세 보기" → `/agent` 전체 레포트 |
| **Slack** | **요약 3~5줄** + 미니 표/차트 1개 | "상세 보기" 링크 |

#### 섹션별 시각 요소 (가능하면 차트/표)

| 섹션 | 시각 | 동반 설명 |
|---|---|---|
| 포트 스냅샷 | **도넛/스택** — 자산군·지역·통화별 현금 | 총자산·전일 대비 한 줄 요약 |
| 수익률 | **막대** — 1d/7d/1mo/Q/YTD | 기간별 해석, 벤치 대비 |
| 환율 | **라인** — USD/KRW·JPY/KRW | 환전 시점·근거 박스 |
| 섹터 흐름 | **히트맵/가로 막대** — 전 섹터 상대강도 | 유입·유출 top3 narrative |
| 스마트 머니 | **막대** — 외국인·기관 순매수 | 기관 vs 개인 렌즈 문단 |
| 맥락·애널 | **카드 목록** — 증권사·의견·한 줄 | 리포트 요약·상반 의견·제안 정합성 |
| 이벤트 | **타임라인** — 전·당·후 | 방향 변경 + 근거 bullet |
| 애널 리포트 (상세) | **표** — 증권사·날짜·의견·목표가 | 종목/섹터 narrative·초보자용 용어 설명 |
| 시나리오 안 | **그룹 막대** Before/After 수익·변동성 + **비중 표** | 안별 playbook + 선택 가이드 |
| Playbook | **플로우 도식** — 환전→매도→매수 | 단계별 금액·%p |
| 방향 변경 | **diff 표** (▲▼ 색상) | 어제→오늘 바뀐 이유 |

#### 설명이 부족하면 안 되는 것 (필수 텍스트)

- 각 차트 **제목 + 한 줄 결론** (caption)
- **기관 vs 개인** 렌즈 (이벤트·섹터마다)
- **Follow / 선점** 각각 2문장 이상 근거
- **환전·리밸런싱 시점** — 왜 지금/왜 보류
- **면책** — 예상 수익률·환율·이벤트 영향

#### 리더빌리티 규칙

- 표: 숫자 **정렬·단위·%p** 통일, 현재→제안 **한 표**에
- 차트: 5초 안에 메시지 전달 (색·범례·라벨 필수)
- 이메일/Slack: **above the fold**에 오늘 결론 3줄 → 상세는 `/agent` 또는 2페이지 이후
- 긴 근거·초보자 설명은 **상세 섹션** — 요약에서 숨기지 않고 "상세에서 설명" 링크

### 기존 앱과의 관계

- **에이전트 전용** `/agent` (대시보드와 분리)
- `lib/` 가격·최적화 로직 공유 가능
- 최적화 앱 = 시뮬레이션, 에이전트 = 실보유 + 시장추세 + 일일 운용

## Key Assumptions to Validate

- [ ] **Must** — 수동 보유 갱신을 꾸준히 할 의향이 있다
- [ ] **Must** — 기관·외국인 방향 + 개인 이점 번역이 신뢰 가능하다
- [ ] **Must** — 주요 이벤트 시 방향·근거 알림으로 놓치지 않는다
- [ ] **Must** — 뉴스·공시·정책이 순수 momentum과 다르게 제안을 바꾼다
- [ ] **Must** — 매일 아침 이메일/Slack이 열어볼 만한 밀도다 (안 열면 실패)
- [ ] **Must** — 미보유 섹터 유입 시 신규 ETF 추천이 실행 가능한 수준이다
- [ ] **Must** — 차트·표만으로는 부족하고, 해석·근거 문단이 함께 있어야 한다
- [ ] **Must** — 1페이지 요약만으로 오늘 할 일이 파악된다
- [ ] **Must** — 상세 페이지에서 초보자가 근거·용어까지 이해할 수 있다
- [ ] **Must** — 통화별 현금 분리 + 환전 시점 제안이 미국 투자 실행에 실질적 도움
- [ ] **Should** — 애널 리포트 요약이 제안 근거와 정합할 때 신뢰가 오른다

## MVP Scope

### 포함

- `/agent` — **요약 랜딩(1페이지)** + **상세 레포트**(섹션·탭), 히스토리, 보유 편집, 채팅
- 초보자용 인라인 용어 설명 (기존 퀀트 앱 InfoTooltip 패턴 재사용)
- 수동 보유: 티커·수량·유형(주식/ETF)·통화, 현금; **보유 종목별** 수익·비중
- 티커 메타: 지역·자산군·**섹터** 분류 (lookup + 사용자 태그 fallback)
- 스마트 머니 신호: 한국 외국인·기관 수급 (가능 범위), 섹터 ETF 흐름
- 맥락: 정책 캘린더, 공시, 뉴스 + **증권사 애널 리포트 요약**(보유·섹터, 출처·날짜)
- **이벤트 알림** — 전·당일·후 방향 제안 + 근거, 이메일/Slack 즉시 발송
- 기관 vs 개인 렌즈 문단 (브리핑 고정 섹션)
- 전 섹터 히트맵 + 미보유 섹터 추천 + 시나리오 Before/After + playbook
- **레포트 시각화** — 섹션별 차트·표·플로우 + caption·근거 문단 (웹·이메일·Slack)

- 시나리오: FX 반영 KRW 기준 수익률 (자산 수익 + 환율 분리 표시)

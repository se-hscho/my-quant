# 포트폴리오 관리 에이전트 — Spec

## 개요

개인 투자자가 국내·미국·일본에 흩어진 주식·ETF·채권·금·현금(통화별)을 수동으로 등록하면, 에이전트가 **기관·외국인 자금 방향**과 **뉴스·공시·정책·증권사 애널 리포트·이벤트**를 반영해 매일 **요약 레포트**와 **상세 설명**을 제공한다. Follow·선점·최소변경 시나리오별로 비중·환전·리밸런싱 시점·조정 playbook·전후 예상 수익률(참고용)을 제시하며, 아침 이메일·Slack과 주요 이벤트 즉시 알림으로 놓치지 않게 한다. 기존 퀀트 최적화 대시보드와 **화면은 분리**되고, 투자 초보자도 이해할 수 있도록 차트·표와 함께 근거 설명·용어 안내를 붙인다.

## 범위

### 포함

- 에이전트 전용 화면 (`/agent`) — 요약 1페이지 + 상세 레포트
- 보유 자산 **수동 입력** — 종목·ETF·채권·금 ETF, **KRW/USD/JPY 현금 분리**
- 자산 범위: 한국·미국·일본 주식·ETF, 채권·금 ETF, 통화별 현금
- 일일 브리핑 생성 — 스마트 머니·전 섹터 흐름·맥락·시나리오·환전·playbook
- 시나리오 **안 0(유지) / 안 1(Follow) / 안 2(선점) / 안 3(최소 변경)** Before/After 비교
- 보유 종목·섹터 ETF 단위 + **미보유 유입 섹터** ETF·종목 추천
- **환전 필요량·시점·근거** (미국·일본 매수 시 USD/JPY 현금 부족 시)
- 증권사 **애널 리포트 공개 요약** 인용 (보유 종목 > 유입 섹터 > 시장)
- 정책·공시·뉴스·이벤트 캘린더 반영 및 **이벤트 시 방향 변경 + 근거**
- **기관 vs 개인** 렌즈 (제약·이점 번역)
- 매일 아침 **이메일·Slack** 요약 알림 (opt-in, 기본 07:00 KST)
- **주요 이벤트 발생 시** 이메일·Slack **즉시** 추가 알림
- 브리핑 히스토리 및 **전일 대비** 제안·시점 diff
- 에이전트 **대화** — 당일 브리핑 맥락 기반 Q&A
- 레포트 **차트·표·도식** + 각 시각 요소별 해석 문단 (초보자용 용어 툴팁)
- 면책 문구 (예상 수익률·투자 권유 아님)

### 제외

- 증권사 계좌 연동·CSV 가져오기 — 수동 입력으로 MVP 단순화
- 사용자 목표 비중 설정·목표 대비 드리프트 UI — 시장·맥락 기반 제안만
- 실거래·자동 매매 — 제안·검토 톤만
- 실시간 호가·체결 시세 — 일봉 기준
- 애널 리포트 전문 전재·유료 리서치 무단 수집 — 공개 요약·인용만
- 13F·펀드 보유 실시간 미러링 — 방향·제약 번역만
- 로그인·다중 사용자 — 개인 단일 사용자 (기존 앱과 동일)

## 시나리오

### 1. 에이전트 요약 페이지 진입

- **Given** — 보유 자산이 1건 이상 등록되어 있고, 당일 브리핑이 생성됨
- **When** — 사용자가 에이전트 화면(`/agent`)에 접속
- **Then** — **요약 페이지**가 표시된다. 오늘 결론 3~5줄, 총자산(KRW 환산)·통화별 현금 스냅샷, 섹터 흐름 상위 3개, 당일·임박 이벤트 유무, 시나리오 안 0~3 한 줄 비교(예상 수익률·변동성), 환전·리밸런싱 시점 한 줄, **상세 보기** 진입 링크 또는 스크롤 안내가 보인다.

성공 기준:
- [ ] 요약 페이지에 오늘 결론 텍스트가 3줄 이상 표시된다
- [ ] 총자산(KRW 환산)과 KRW/USD/JPY 현금 비중 또는 잔액이 표시된다
- [ ] 섹터 자금 흐름 상위 3개가 표 또는 차트로 표시된다
- [ ] 시나리오 안 0~3의 예상 수익률·변동성을 한눈에 비교할 수 있는 시각 요소가 1개 이상 있다
- [ ] 환전 또는 리밸런싱 시점 요약이 1줄 이상 표시된다
- [ ] 상세 레포트로 이동할 수 있는 링크 또는 UI가 보인다

---

### 2. 상세 레포트 — 섹션·초보자 설명

- **Given** — 당일 브리핑이 생성된 상태에서 요약 페이지
- **When** — 사용자가 **상세 보기**로 이동하거나 아래로 스크롤
- **Then** — 섹션별로 **차트 또는 표**와 **해석 문단**(2문장 이상)이 쌍으로 표시된다. 섹션은 최소 다음을 포함한다: 포트 스냅샷·수익률(1d/7d/1mo/분기/YTD), 환율·환전, 스마트 머니·전 섹터 흐름, 맥락(뉴스·공시·정책·애널), 이벤트, 기관 vs 개인, 신규 추천, 시나리오·playbook, 방향 변경 diff. 금융 용어 첫 등장 시 **? 툴팁** 또는 인라인 설명이 있다.

성공 기준:
- [ ] 상세 레포트에 위 9개 주제 중 8개 이상의 구분된 섹션이 있다
- [ ] 각 섹션에 차트 또는 표가 1개 이상 있다
- [ ] 각 차트·표 아래에 해석 문단이 2문장 이상 있다
- [ ] %p·순매수·Follow 등 용어에 초보자용 설명 UI가 1곳 이상 있다
- [ ] 면책 문구가 상세 레포트 하단 또는 고정 영역에 표시된다

---

### 3. 보유 자산 수동 등록

- **Given** — 에이전트 보유 편집 화면, 보유가 비어 있음
- **When** — 사용자가 티커·수량·자산 유형(주식/ETF/채권ETF/금ETF)·결제 통화를 입력하고 KRW·USD·JPY 현금 잔액을 각각 입력한 뒤 저장
- **Then** — 보유 목록에 해당 종목과 통화별 현금이 표시되고, 총자산(KRW 환산)이 갱신된다.

성공 기준:
- [ ] 티커·수량·자산 유형·통화를 입력할 수 있는 폼이 있다
- [ ] KRW·USD·JPY 현금을 **각각** 입력할 수 있다
- [ ] 저장 후 보유 목록에 종목과 통화별 현금이 표시된다
- [ ] 총자산 금액(KRW 환산)이 화면에 표시된다

---

### 4. 알 수 없는 티커 — 섹터 태그 지정

- **Given** — 보유 편집 중, 시스템이 섹터를 자동 분류하지 못한 티커
- **When** — 사용자가 해당 티커 저장 시도
- **Then** — 섹터(및 필요 시 지역) 태그를 선택하도록 안내되고, 지정 후 저장되면 이후 브리핑에 해당 섹터로 반영된다.

성공 기준:
- [ ] 자동 분류 실패 티커 저장 시 섹터 선택 UI가 표시된다
- [ ] 섹터 지정 후 저장하면 보유 목록에 섹터 정보가 표시된다

---

### 5. 전 섹터 자금 흐름 — 보유와 무관

- **Given** — 보유가 특정 섹터(예: 반도체)에 편중되어 있음
- **When** — 사용자가 당일 상세 레포트의 섹터 흐름 섹션 확인
- **Then** — **보유 여부와 관계없이** 복수 섹터의 상대강도(예: 7일)가 히트맵 또는 가로 막대 차트로 표시되고, 유입·유출 상위 섹터 해석 문단이 있다.

성공 기준:
- [ ] 5개 이상 섹터의 상대강도가 한 차트 또는 표에 표시된다
- [ ] 보유하지 않은 섹터도 목록에 포함된다
- [ ] 유입 상위·유출 섹터에 대한 해석 문단이 있다

---

### 6. 미보유 섹터 — ETF·종목 추천

- **Given** — 유입 상위 섹터 중 사용자가 보유하지 않은 섹터가 있음
- **When** — 사용자가 신규 추천 섹션 확인
- **Then** — 해당 섹터의 **대표 ETF 또는 종목 티커**가 1개 이상 제안되고, 유입 근거(섹터 수익률·수급 등) 문장이 붙는다.

성공 기준:
- [ ] 미보유 유입 섹터마다 추천 티커가 1개 이상 표시된다
- [ ] 각 추천에 섹터 유입 근거 문장이 1문장 이상 있다
- [ ] 추천 톤이 "검토"·"고려"이며 확정 매수 지시 문구가 아니다

---

### 7. 시나리오 안 — Before/After 비교

- **Given** — 보유 등록 완료, 당일 브리핑 생성됨
- **When** — 사용자가 시나리오 섹션 확인
- **Then** — **안 0(유지)·안 1(Follow)·안 2(선점)·안 3(최소 변경)** 이 모두 표시되고, 각 안에 대해 Before(현재)와 After의 **예상 수익률·예상 변동성**(참고용 표기), 자산군·지역·섹터·**보유 종목** 비중 표, 통화별 현금 변화가 비교된다.

성공 기준:
- [ ] 안 0·1·2·3 네 가지가 모두 표시된다
- [ ] 각 안에 Before/After 예상 수익률이 표시되고 "참고용·보장 아님" 표기가 있다
- [ ] 각 안에 보유 종목 단위 비중 Before/After가 표로 표시된다
- [ ] 안 1·2·3 중 최소 1개에 After 비중 합이 100%(±0.1%p)로 표시된다

---

### 8. Playbook — 환전·매수·매도 순서

- **Given** — 안 1 또는 2에서 미국 자산 비중 확대가 제안되고, USD 현금이 부족한 상태
- **When** — 사용자가 해당 안의 playbook 확인
- **Then** — 조정 단계가 **번호 순서**로 표시되며, **환전(KRW→USD 등)이 매수보다 앞**에 오고, 각 단계에 티커·비중 변화(%p)·재원(통화)이 명시된다.

성공 기준:
- [ ] playbook이 순서 있는 목록 또는 플로우 도식으로 표시된다
- [ ] USD 부족 시 환전 단계가 첫 단계(0단계)로 표시된다
- [ ] 각 단계에 %p 변화와 사용 통화가 표시된다
- [ ] 환전만 제안하고 매수는 보류하는 단계 구성이 가능한 안에서 구분 표시된다

---

### 9. 환전 시점·근거

- **Given** — 환전이 필요한 시나리오 안이 존재
- **When** — 사용자가 환율·환전 섹션 확인
- **Then** — USD/KRW(및 해당 시 JPY/KRW) 추세 차트, **환전 권장 시점**(즉시·N일 내·이벤트 후·보류), **환전 금액**, **근거**(환율 추세·금리·정책 이벤트 등)가 표시된다.

성공 기준:
- [ ] USD/KRW 환율 추세 차트가 1개 이상 표시된다
- [ ] 환전 권장 시점이 텍스트로 명시된다
- [ ] 환전 금액(KRW 및 환산 USD)이 표시된다
- [ ] 환전 시점 근거 문단이 2문장 이상 있다

---

### 10. 예상 수익률 — 자산 vs 환율 분리

- **Given** — 미국 자산을 보유하거나 미국 비중 확대가 제안된 안
- **When** — 사용자가 해당 안의 수익률 상세 확인
- **Then** — KRW 기준 예상 수익률이 **자산 수익**과 **환율 영향**으로 분리 표시되거나, 합산과 분리 항목이 함께 표시된다.

성공 기준:
- [ ] KRW 기준 예상 수익률 옆 또는 아래에 환율 영향 항목이 표시된다
- [ ] 자산 수익과 환율 영향이 구분되어 보인다

---

### 11. 스마트 머니 — 외국인·기관 수급

- **Given** — 한국 시장 관련 보유 또는 섹터가 브리핑에 포함됨
- **When** — 사용자가 스마트 머니 섹션 확인
- **Then** — 외국인·기관 순매수(또는 순매도)가 섹터·시장 단위 차트로 표시되고, **기관 vs 개인** 렌즈 문단(기관 제약·개인 이점)이 있다.

성공 기준:
- [ ] 외국인 또는 기관 수급 데이터가 차트 또는 표로 표시된다
- [ ] "기관 vs 개인" 제목 또는 이에 상응하는 문단이 3문장 이상 있다

---

### 12. 맥락 — 뉴스·공시·정책

- **Given** — 당일 또는 전일 주요 정책·보유 종목 공시·뉴스가 존재
- **When** — 사용자가 맥락 브리핑 섹션 확인
- **Then** — 항목별 요약(제목·한 줄 내용)이 카드 또는 목록으로 표시되고, 포트폴리오 제안에 미치는 영향 해석이 붙는다.

성공 기준:
- [ ] 맥락 항목이 1건 이상 목록으로 표시된다
- [ ] 각 항목 또는 섹션에 "제안에 미치는 영향" 해석이 1문장 이상 있다

---

### 13. 증권사 애널 리포트 인용

- **Given** — 보유 종목 또는 유입 섹터에 대해 공개 애널 요약이 수집됨
- **When** — 사용자가 애널 리스트 섹션 확인
- **Then** — **증권사명·날짜·투자의견**(가능 시 목표가)·한 줄 요약이 표로 표시되고, 상세에서 리포트 요약·상반 의견·당일 제안과의 정합성 설명이 있다. 동일 종목에 복수 리포트 시 2건 이상 나란히 보인다.

성공 기준:
- [ ] 애널 표에 증권사명과 날짜가 표시된다
- [ ] 투자의견(Buy/Hold/Sell 등) 또는 이에 상응하는 라벨이 표시된다
- [ ] 상세 섹션에 제안과의 정합성 설명이 2문장 이상 있다
- [ ] 공개 원문 URL이 있을 때 링크가 표시된다

---

### 14. 애널 데이터 없음

- **Given** — 특정 보유 종목에 수집된 애널 요약이 없음
- **When** — 사용자가 해당 종목 관련 브리핑 확인
- **Then** — "애널 리포트 요약 없음"이 명시되고, 수급·가격·뉴스 등 **다른 근거**로 제안이 구성됨이 보인다.

성공 기준:
- [ ] 애널 없음 상태가 "데이터 없음" 등으로 명시된다
- [ ] 해당 종목 제안에 수급·가격·뉴스 중 1가지 이상 다른 근거가 문장으로 표시된다

---

### 15. 이벤트 — 방향 변경 즉시 알림

- **Given** — 사용자가 이메일 또는 Slack 알림을 켜 둠, 등록된 주요 이벤트(예: FOMC, 보유 종목 실적 발표)가 **당일 발생**함
- **When** — 이벤트 결과가 브리핑에 반영됨
- **Then** — 아침 정기 브리핑과 **별도로** 이메일 또는 Slack에 **즉시** 알림이 발송된다. 알림에 **배분 방향 변경 요약**, **근거**(이벤트 내용·수치·애널·수급), **상세 보기 링크**가 포함된다.

성공 기준:
- [ ] 이벤트 반영 후 30분 이내(또는 브리핑 갱신 직후) 알림이 발송된다
- [ ] 알림 본문에 방향 변경 요약이 3줄 이내로 있다
- [ ] 알림에 근거 문장이 1문장 이상 있다
- [ ] 상세 레포트 URL 링크가 있다

---

### 16. 이벤트 상세 — 전·당일·후

- **Given** — 임박 또는 당일 이벤트가 캘린더에 있음
- **When** — 사용자가 이벤트 섹션 확인
- **Then** — 타임라인(전·당일·후)이 표시되고, 각 시점별 **검토할 배분 방향**과 근거가 bullet로 있다.

성공 기준:
- [ ] 이벤트 타임라인 UI가 표시된다
- [ ] 당일 또는 전 시점에 "검토 방향" bullet이 1개 이상 있다
- [ ] 각 bullet에 근거 문장이 붙어 있다

---

### 17. 매일 아침 정기 알림

- **Given** — 이메일 또는 Slack 알림 활성화, 보유 등록됨, 알림 시각 07:00 KST(기본)
- **When** — 당일 07:00 KST 경과 후
- **Then** — 이메일 또는 Slack에 **요약본**이 도착한다. 본문에 오늘 결론 3줄, 핵심 차트 또는 표 이미지 1~2개, 환전·시점 한 줄, 상세 보기 링크가 있다.

성공 기준:
- [ ] 설정 시각 ±15분 내에 알림이 도착한다
- [ ] 요약 결론이 3줄 이상이다
- [ ] 차트 또는 표 이미지/블록이 1개 이상 포함된다
- [ ] 상세 레포트 링크가 포함된다

---

### 18. 알림 설정

- **Given** — 에이전트 설정 화면
- **When** — 사용자가 이메일 주소·Slack Webhook URL·아침 시각·채널별 on/off 저장
- **Then** — 설정이 유지되며 이후 알림이 해당 채널·시각에 맞게 발송된다.

성공 기준:
- [ ] 이메일·Slack 각각 활성/비활성 토글이 있다
- [ ] 아침 발송 시각을 변경할 수 있다
- [ ] 저장 후 재접속 시 설정이 유지된다

---

### 19. 전일 대비 방향 변경 diff

- **Given** — 전일 브리핑과 당일 브리핑이 모두 존재, 제안 내용에 차이가 있음
- **When** — 사용자가 방향 변경 섹션 확인
- **Then** — 변경된 섹터·종목·시나리오·환전 시점이 **diff 표**(▲▼)로 표시되고, 변경 이유 문단이 있다.

성공 기준:
- [ ] 전일 대비 변경 항목이 표로 1건 이상 표시된다
- [ ] 증가·감소 또는 채택·보류가 시각적으로 구분된다
- [ ] 변경 이유 문단이 2문장 이상 있다

---

### 20. 브리핑 히스토리

- **Given** — 과거 브리핑이 2일 이상 저장됨
- **When** — 사용자가 히스토리 목록 접속 후 특정 날짜 선택
- **Then** — 해당 날짜의 요약·상세 레포트를 다시 볼 수 있다.

성공 기준:
- [ ] 날짜별 브리핑 목록이 최신순으로 표시된다
- [ ] 날짜 선택 시 해당 일자 요약·상세가 표시된다

---

### 21. 에이전트 대화

- **Given** — 당일 브리핑이 생성된 상태
- **When** — 사용자가 채팅에 "안 2만 자세히 설명해줘" 또는 "에너지 ETF 대안은?" 입력
- **Then** — 당일 보유·브리핑·시나리오 맥락을 반영한 답변이 표시되고, 초보자용 설명 톤을 유지한다.

성공 기준:
- [ ] 채팅 입력창과 전송 UI가 있다
- [ ] 질문 후 에이전트 답변이 화면에 표시된다
- [ ] 답변에 당일 브리핑에 존재하는 안 번호·섹터·티커 중 1개 이상이 언급된다

---

### 22. 보유 없이 에이전트 접속

- **Given** — 보유 자산이 등록되지 않음
- **When** — 사용자가 `/agent` 접속
- **Then** — **예시 포트폴리오 미리보기**로 브리핑 요약(시나리오·섹터·결론)을 체험할 수 있고, 등록 안내·CTA로 보유 편집으로 이동할 수 있다.

성공 기준:
- [ ] `예시 포트폴리오 미리보기` 배너 또는 동등한 안내가 표시된다
- [ ] `summary-page`(시나리오 비교·오늘 결론)가 표시된다 — 실패 시 구조화 오류(`code`, `detail`)가 표시된다
- [ ] 보유 편집 화면으로 이동하는 버튼 또는 링크가 있다
- [ ] 예시와 실보유가 혼동되지 않도록 면책·라벨이 표시된다

---

### 23. 브리핑 생성 실패

- **Given** — 보유는 있으나 시세·외부 데이터 수집 실패
- **When** — 브리핑 생성 시도
- **Then** — "브리핑을 생성하지 못했습니다" 안내와 재시도 버튼이 표시되고, 부분 데이터만으로는 **완전한 시나리오 안을 표시하지 않는다**.

성공 기준:
- [ ] 실패 안내 메시지가 표시된다
- [ ] 재시도 버튼이 표시된다
- [ ] 불완전한 시나리오 안 0~3이 "참고용 완성본"으로 표시되지 않는다
- [ ] 검증용으로 오류 `code`·`detail`(API 단계 포함)이 UI에 표시된다

---

## 불변 규칙

**톤·면책**
- 모든 레포트·알림·채팅에 **투자 권유가 아님**·**예상 수익률은 참고용** 면책이 표시된다.
- 사용자에게 보이는 모든 제안 문구는 **"검토"·"고려"** 톤이며, "반드시 매수/매도" 등 확정 지시 표현을 쓰지 않는다.

**데이터 표시**
- 시나리오 After 비중(자산군·종목·현금 포함) 합계는 **100%(±0.1%p)** 로 표시된다.
- 애널 인용 시 **증권사명·날짜**가 있으면 반드시 함께 표시된다. 없으면 "출처 미상"으로 표시하지 않고 해당 인용을 생략한다.
- 차트·표마다 **제목**과 **한 줄 결론(caption)** 이 있다.

**정보 구조**
- 웹 레포트는 **요약 페이지가 상세보다 먼저** 노출된다.
- 이메일·Slack 정기 알림은 **요약만** 보내고, 전체 상세는 웹 링크로 연결한다.
- 주요 이벤트 알림은 정기 아침 알림과 **별도 발송**된다.

**자산·통화**
- 한국 종목 매수 제안의 재원은 **KRW 현금**에서만 온다.
- 미국·일본 종목 매수 제안은 **해당 통화 현금**을 우선 사용하고, 부족 시 **환전 단계**가 playbook에 포함된다.

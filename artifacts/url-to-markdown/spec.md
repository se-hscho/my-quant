## 개요

웹 페이지 URL을 Markdown으로 변환하고, LLM(ChatGPT·Claude)으로 바로 넘길 수 있는 단일 페이지 서비스.
사용자는 URL을 붙여넣고 변환된 내용을 복사·다운로드하거나 LLM 서비스로 즉시 이동할 수 있다.

## 범위

### 포함
- URL 입력 및 Markdown 변환 (defuddle 라이브러리 사용)
- 변환 결과 렌더링 미리보기 (페이지 제목·저자 헤더 포함)
- 내보내기: 클립보드 복사, .md 파일 다운로드
- LLM으로 열기: ChatGPT / Claude (URL ?q= 파라미터, 새 탭)
- 프롬프트: 프리셋 3종 + 직접 입력 (1회용, 저장 안 함)
- 다크모드 토글
- 에러 토스트 알림

### 제외
- 사용자 인증 / 로그인 — 단순 유틸 서비스로 인증 불필요
- 변환 이력 저장 — 1회성 사용 패턴; 저장소 연동은 별도 feature
- 다중 URL 동시 변환 — MVP 범위 밖
- 마크다운 편집 — 변환 결과는 읽기 전용

## 시나리오

### 1. URL 입력 및 변환

- **Given** — 앱이 처음 로드된 상태
- **When** — 화면을 확인하면
- **Then** — URL 입력 필드, 변환 버튼, 다크모드 토글이 표시된다

성공 기준:
- [ ] 앱 진입 시 URL 입력 필드가 비어 있고 포커스를 받는다
- [ ] 변환 버튼이 표시된다

---

- **Given** — URL 입력 필드에 유효한 URL이 입력된 상태
- **When** — 변환 버튼을 클릭하거나 Enter 키를 누르면
- **Then** — 로딩 인디케이터가 표시된다

성공 기준:
- [ ] `https://example.com` 입력 후 변환 시작 시 로딩 상태가 화면에 나타난다

---

- **Given** — 변환이 완료된 상태
- **When** — 결과 영역을 확인하면
- **Then** — 페이지 제목과 저자 정보를 헤더로 포함한 렌더링된 Markdown이 표시된다

성공 기준:
- [ ] 결과 영역에 페이지 제목 텍스트가 표시된다
- [ ] 결과 영역에 저자 정보가 표시된다 (페이지에 저자 정보가 있는 경우)
- [ ] 본문 내용이 렌더링된 HTML 형태로 표시된다

### 2. URL 지우기 (리셋)

- **Given** — URL 입력 필드에 내용이 입력된 상태
- **When** — 지우기 버튼(×)을 클릭하면
- **Then** — URL 입력 필드가 비워지고 변환 결과도 사라진다

성공 기준:
- [ ] URL 입력 필드가 빈 상태가 된다
- [ ] 변환 결과 영역이 사라진다

### 3. 에러 처리

- **Given** — 입력 필드에 잘못된 URL(예: `not-a-url`)이 입력된 상태
- **When** — 변환 버튼을 클릭하면
- **Then** — 에러 내용을 담은 토스트 메시지가 표시된다

성공 기준:
- [ ] `not-a-url` 입력 후 변환 시도 시 토스트 에러 메시지가 나타난다
- [ ] 에러 후에도 URL 입력 필드는 그대로 유지된다

---

- **Given** — 유효한 URL이지만 접속 불가능하거나 변환에 실패한 상태
- **When** — 변환이 완료되면
- **Then** — 실패 원인을 설명하는 토스트 메시지가 표시된다

성공 기준:
- [ ] 서버 응답 없음 등 실패 시 토스트 에러 메시지가 나타난다
- [ ] 로딩 인디케이터가 사라진다

### 4. 내보내기 — 복사

- **Given** — 변환 결과가 표시된 상태
- **When** — "복사하기" 버튼을 클릭하면
- **Then** — raw Markdown 내용이 클립보드에 복사된다

성공 기준:
- [ ] "복사하기" 버튼 클릭 후 클립보드에 `#`으로 시작하는 Markdown 텍스트가 담긴다
- [ ] 복사 성공 피드백(예: 버튼 텍스트 변경 또는 토스트)이 표시된다

### 5. 내보내기 — .md 파일 다운로드

- **Given** — 변환 결과가 표시된 상태
- **When** — ".md 다운로드" 버튼을 클릭하면
- **Then** — raw Markdown 내용을 담은 `.md` 파일이 다운로드된다

성공 기준:
- [ ] `.md` 확장자를 가진 파일 다운로드가 시작된다
- [ ] 다운로드된 파일 내용이 복사 결과와 동일하다

### 6. LLM으로 열기 — 프롬프트 없음

- **Given** — 변환 결과가 표시되고 프롬프트를 선택하지 않은 상태
- **When** — "ChatGPT로 열기" 버튼을 클릭하면
- **Then** — `chatgpt.com`에 Markdown 내용이 담긴 새 탭이 열린다

성공 기준:
- [ ] 새 탭이 열린다
- [ ] URL의 `q` 파라미터에 Markdown 내용이 포함된다

---

- **Given** — 변환 결과가 표시되고 프롬프트를 선택하지 않은 상태
- **When** — "Claude로 열기" 버튼을 클릭하면
- **Then** — `claude.ai`에 Markdown 내용이 담긴 새 탭이 열린다

성공 기준:
- [ ] 새 탭이 열린다
- [ ] URL의 `q` 파라미터에 Markdown 내용이 포함된다

### 7. LLM으로 열기 — 프롬프트 있음

- **Given** — 변환 결과가 표시되고 프롬프트 프리셋("요약해줘")이 선택된 상태
- **When** — "ChatGPT로 열기" 또는 "Claude로 열기" 버튼을 클릭하면
- **Then** — `{prompt}\n\n{markdown}` 형식의 내용이 담긴 새 탭이 열린다

성공 기준:
- [ ] URL의 `q` 파라미터가 `요약해줘\n\n{markdown}` 형식으로 인코딩된다
- [ ] 새 탭으로 이동된다

---

- **Given** — 변환 결과가 표시되고 "직접 입력" 모드에서 커스텀 프롬프트를 작성한 상태
- **When** — LLM으로 열기 버튼을 클릭하면
- **Then** — `{custom_prompt}\n\n{markdown}` 형식으로 새 탭이 열린다

성공 기준:
- [ ] URL의 `q` 파라미터에 입력한 커스텀 프롬프트가 마크다운 앞에 포함된다

### 8. 프롬프트 선택

- **Given** — 변환 결과가 표시된 상태
- **When** — 프롬프트 영역을 확인하면
- **Then** — "요약해줘", "한국어로 번역해줘", "쉽게 설명해줘", "직접 입력" 옵션이 표시된다

성공 기준:
- [ ] 4가지 옵션 레이블이 화면에 표시된다

---

- **Given** — 프롬프트 영역에서 "직접 입력"을 선택하면
- **When** — 프롬프트 입력 영역을 확인하면
- **Then** — 텍스트를 입력할 수 있는 입력 필드가 나타난다

성공 기준:
- [ ] "직접 입력" 선택 시 텍스트 입력 필드가 표시된다
- [ ] 페이지를 새로고침하면 직접 입력 내용이 사라진다 (1회용, 저장 안 함)

### 9. 다크모드 토글

- **Given** — 라이트 모드인 상태
- **When** — 다크모드 토글 버튼을 클릭하면
- **Then** — 화면 전체가 다크 테마로 전환된다

성공 기준:
- [ ] 토글 클릭 시 배경이 어두운 색으로 바뀐다
- [ ] 다시 클릭하면 라이트 모드로 돌아온다

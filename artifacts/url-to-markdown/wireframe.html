  • 트리거: 앱 진입 시
  • 인터랙션: URL 붙여넣기 → 입력 필드에 텍스트 + × 버튼 출현 / 변환하기 또는 Enter → 로딩 중
  • 전환: 변환 시작 → ② 로딩 중

Notes

URL 오류·접속 실패 시 토스트 표시. 입력 필드 유지.

  • 트리거: 잘못된 URL 입력 후 변환 시도 / 접속 불가·변환 실패

  • 전환: 토스트 닫힘 → 입력 대기

# Spec: 사용자 번들 추가하기

## 개요

홈 갤러리에서 사용자가 직접 종목 묶음(번들)을 만들어 저장하고, 기존 번들과 동일한 최적화 흐름을 사용할 수 있다.

---

## 시나리오

### S1. 번들 생성 — Happy Path

**Given** 사용자가 홈(`/`) 갤러리를 보고 있다  
**When** "번들 추가하기" 버튼을 클릭한다  
**Then** 번들 생성 폼(또는 모달)이 열린다

---

**Given** 번들 생성 폼이 열려 있다  
**When** 이름, 카테고리, 종목(ticker) 2개 이상을 입력하고 저장한다  
**Then**
- 폼이 닫힌다
- 새 번들 카드가 갤러리에 즉시 나타난다
- 새 번들 카드에 사용자가 입력한 이름·카테고리가 표시된다

---

### S2. 카테고리 입력

**Given** 카테고리 입력 영역이 있다  
**When** 사용자가 카테고리를 선택·입력한다  
**Then** 두 가지 방식이 모두 가능하다:
- 기존 카테고리(테마형, 팩터형, 전통 배분, 기관 따라하기) 중 선택
- 위 목록에 없는 텍스트를 직접 입력하여 새 카테고리 지정

**And** 직접 입력한 카테고리로 저장된 번들은 갤러리 카테고리 필터에 해당 카테고리로 노출된다

---

### S3. 종목 추가

**Given** 종목 입력 필드가 있다  
**When** 사용자가 ticker를 입력하고 추가한다  
**Then** 해당 ticker가 종목 목록에 추가된다

**Given** 이미 추가된 ticker와 동일한 값을 입력한다  
**When** 추가를 시도한다  
**Then** 중복 추가되지 않으며 안내 메시지가 표시된다

---

### S4. 저장 유효성 검사

**Given** 종목이 1개 이하인 상태다  
**When** 저장을 시도한다  
**Then** 저장되지 않으며 "종목을 2개 이상 추가해주세요" 안내가 표시된다

**Given** 번들 이름이 비어 있다  
**When** 저장을 시도한다  
**Then** 저장되지 않으며 이름 입력을 요구하는 안내가 표시된다

---

### S5. 사용자 번들 삭제

**Given** 갤러리에 사용자가 만든 번들 카드가 있다  
**When** 카드의 삭제 버튼을 누르고 확인한다  
**Then** 해당 번들이 갤러리에서 사라지고 다시 나타나지 않는다

**Given** 기본 제공 번들 카드를 본다  
**Then** 삭제 버튼이 없다 (기본 번들은 삭제 불가)

---

### S6. 최적화 흐름 연결

**Given** 사용자가 만든 번들 카드가 갤러리에 있다  
**When** 카드를 클릭한다  
**Then** 기존 번들과 동일하게 `/bundle/[id]` 상세 페이지로 이동하고 최적화를 실행할 수 있다

---

### S7. 새로고침 후 유지

**Given** 사용자가 번들을 저장했다  
**When** 페이지를 새로고침하거나 브라우저를 닫고 다시 연다  
**Then** 저장된 번들이 갤러리에 계속 표시된다

---

### S8. 카테고리 필터

**Given** 사용자 번들이 기존 카테고리(예: 테마형)로 저장됐다  
**When** 갤러리에서 "테마형" 필터를 선택한다  
**Then** 해당 번들이 기본 번들과 함께 표시된다

**Given** 사용자 번들이 신규 카테고리(예: "내 전략")로 저장됐다  
**When** 갤러리를 본다  
**Then** "내 전략" 필터 버튼이 카테고리 목록에 추가되어 있고, 해당 필터로 그 번들만 볼 수 있다

---

## 불변 규칙

- 기본 제공 번들(config에 정의된 번들)은 수정·삭제할 수 없다.
- 번들은 브라우저 로컬 저장소에 저장된다. 다른 기기·브라우저와 공유되지 않는다.
- 종목 수정(추가/삭제)은 이번 범위에서 제외한다. 번들 생성 시에만 종목을 지정한다.

---

## 제외 항목

- **ticker 유효성 실시간 검증** (야후 파이낸스 조회): 잘못된 ticker는 최적화 실행 시 에러로 노출됨. 생성 시점 검증은 v2로 미룸
- **번들 수정**: 생성 후 이름·종목 편집은 이번 범위 제외
- **번들 공유/내보내기**: 로컬 저장만 지원
